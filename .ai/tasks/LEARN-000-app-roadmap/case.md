# LEARN-000 — Мастер-roadmap учебного приложения

## Исходная задача

Собрать учебный MVP dealing-console-v2: рабочая звонковая часть пульта на стеке Vue 3 + TypeScript + Pinia + FSD, с подключением к RTU/APS и SIP/WebRTC как на стенде. Параллельно — обучение на каждом шаге, без полного паритета production.

Репозиторий стартует почти с нуля (`AGENTS.md`, `.ai/`, `.reference/`, `.npmrc`).

## Уточнения пользователя (2026-09-16)

- **Опыт / темп:** средний (1B) — шаги не микроскопические, но атомарные под один коммит; фокус обучения на стеке.
- **Порядок:** сначала подключение к стенду (config → auth → API → SIP), затем натягивание UI.
- **ПБВ:** реализовать **полностью** (как web-сценарий в референсе); контекстное меню — общий `shared`-компонент/composable, переиспользуется на других страницах/панелях.
- **Завешенные + карточка:** ближе к проду — mute / hold / speaker и ключевые состояния call card (вариант B).
- **Scaffold:** чистый Vite + FSD-скелет руками (максимум обучения), не копировать проект целиком из `.reference`.
- **Auth/config:** как в проде, упрощённо (happy-path стенда).
- **Настройки:** список устройств + выбор устройства для завешенных (web MediaDevices; Goose/Handset/Electron — позже).
- **i18n:** не делаем; весь UI-текст на русском в коде.
- **Кто пишет код:** в основном разработчик; агент — план, ревью, подсказки; код/болванки — только по явной просьбе.

## Ограничения

- Не трогать `.reference/` (read-only).
- Не добавлять зависимости без согласования.
- Electron / controller WS / аппаратные устройства — отдельная фаза после web-MVP.
- Vitest — отдельная учебная фаза в конце.
- Дипломная документация вне этого репозитория.
- Коммиты делает разработчик.

## Принципы нарезки

1. `LEARN-000` — только roadmap фаз и список дочерних `LEARN-NNN` (без мелкой реализации).
2. Каждый дочерний `LEARN-NNN` получает свой `case.md` + `implementation_plan_1.md` со шагами = будущие коммиты.
3. После scaffold приоритет у интеграций (стенд), UI — поверх уже работающего SIP/API.
4. Контекстное меню появляется один раз в `shared` и подключается в ПБВ / завешенных / при необходимости в других местах без копипасты.
