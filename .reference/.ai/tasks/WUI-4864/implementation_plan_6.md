# Кейс: WUI-4864 — UI статусов карточки ПБВ (токены, иконки, L/R, pinned)

## Описание текущей части кейса

Добить визуал self-статусов карточки панели быстрого вызова по дизайн-системе: цвета через существующие theme-токены, иконки (пользователь проставит имена сам), направление L/R от устройства сессии (handset и goose), иконка завешенных по сессии, high priority только заложить. Конференции в приложении пока нет — ветки conference в модели карточки убрать/не поддерживать. Макет пользователь пришлёт отдельно; Figma API сейчас с лимитом.

Уточнения от 2026-07-14:

- Логика статусов та же, что сейчас (incoming / outgoing / connected / hold); меняются только иконки в зависимости от устройства/стороны сессии; **цвета статусов одинаковые** (не зависят от L/R и handset vs goose).
- L/R и тип устройства брать из **устройства сессии** (упрощённо).
- Завешенные: смотреть по **сессии** (pinned store); при pinned на разговоре — иконка mic завешенных вместо обычной connected-иконки.
- Goose hold: пока **заглушка** (плейсхолдер-иконка), пользователь поправит.
- High priority incoming: заложить в contract; с бэка / wiring группы пока нет.
- Конференции: в приложении не предусмотрены — `conference-self` / `conference-hold-self` убрать из модели карточки; при появлении — отдельной задачей.
- Токены цветов должны уже быть в файлах темы; при сверке с макетом **помечать отсутствующие**.
- Иконки в contract пользователь проставит сам (в коде оставить явные placeholder / текущие имена до его правок).
- Работу разбить на несколько планов/шагов; тесты и wiki — **в конце** (не в каждом шаге).

# План реализации: UI статусов карточки ПБВ

## Шаг 1: Упростить модель self-статусов без conference

- **Статус:** Выполнен (ожидает коммита пользователя).
- **Описание:** Из `useContactCardStatus` убрать ветки `conference-self` / `conference-hold-self`. Сессия в `CONNECTED` / `ONHOLD` всегда мапится в `connected-self` / hold по `direction`, без учёта `session.conference`. Обновить типы и tone-таблицу: удалить conference-ключи.
- **Файлы для изменений:** `use-contact-card-status.ts`, `contact-card-tone.ts`; связанные импорты типов.
- **Ожидаемый результат:** В модели карточки только: incoming / outgoing / connected / incoming-hold / outgoing-hold (+ base без self).
- **Проверка:** `npm run ts:check`.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Нет (в конце кейса)

## Шаг 2: Контекст сессии для иконки (device side + pinned)

- **Статус:** Выполнен (ожидает коммита пользователя).
- **Описание:** Рядом со статусом научиться доставать из локальной сессии контакта: сторону модуля L/R (handset left/right или goose `L*`/`R*`) и факт «сессия в завешенных» через `usePinnedCallsPanelStore.slotSessionIds` по sessionId. Цвета от side/device **не** зависят. На этом шаге можно вернуть сырой контекст из composable без финальной матрицы иконок.
- **Файлы для изменений:** `use-contact-card-status` и/или новый мелкий helper в model ПБВ; использование pinned-store через public API entity/feature.
- **Ожидаемый результат:** Карточка/модель знает `selfStatus`, `deviceSide: 'L' | 'R'`, `isPinnedSession: boolean` (и при необходимости тип handset|goose для goose-hold заглушки).
- **Проверка:** `npm run ts:check`.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Нет

## Шаг 3: Visual contract — иконки L/R, pinned, goose-hold stub, high incoming

- **Статус:** Выполнен (ожидает коммита пользователя).
- **Описание:** Расширить `getContactCardTone`: при выборе иконки учитывать side (mirror как в call-card), pinned → mic на connected, goose hold → placeholder. High/default только для `incoming-self` по цвету (как сейчас). Имена иконок — временные/текущие; пользователь проставит финальные сам. Цветовые классы — существующие `card-deal-*`; при сверке с макетом пользователя пометить недостающие токены комментарием/`TODO` в коде или списком в ответе, **не** выдумывать новые без сверки.
- **Файлы для изменений:** `contact-card-tone.ts`, `QuickCallContactCard.vue` (прокинуть контекст в tone).
- **Ожидаемый результат:** Одна точка правды по визуалу self-статусов; L/R и pinned влияют только на icon name.
- **Проверка:** `npm run ts:check`; ручная проверка направлений на left/right handset и goose при наличии железа.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Нет
