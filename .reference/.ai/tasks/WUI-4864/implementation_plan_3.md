# Кейс: WUI-4864 — перемещение контактов в сетке ПБВ

## Описание текущей части кейса

Следующая часть WUI-4864 касается перемещения контактов в панели быстрого вызова. Порядок внутри группы пока хранится локально во frontend-модели `useQuickCallGrid`, потому что нового backend для позиций карточек еще нет. Перемещение контакта между группами нужно реализовать уже сейчас через существующий backend состава групп: добавить существующий контакт в целевую группу и удалить его из исходной группы.

Группы в будущем можно будет создавать и на странице настроек, и прямо в панели быстрого вызова. Контакты в группы можно будет добавлять и в настройках, и в ПБВ. В этой части не реализуется создание групп.

# План реализации: перемещение контактов в ПБВ

## Шаг 1: Перемещение контакта внутри текущей группы

- **Описание:** Добавить локальный сценарий перемещения карточки внутри активной группы через `useQuickCallGrid`. В режиме редактирования по кнопке с тремя точками открыть простое контекстное меню. Если группа одна, показать пункты `Переместить` и `Удалить`; если групп несколько, показать `Переместить в другую группу`, `Переместить`, `Удалить`, но в этом шаге реализовать только `Переместить` внутри текущей группы. После выбора `Переместить` контакт переходит в pending move state, свободные ячейки становятся целями, клик по свободной ячейке переносит `contactGuid` в выбранный `cellIndex`. Клик по исходной карточке или выход из edit mode отменяет перемещение. Изменение order пока не отправляется на backend, но action должен быть выделен так, чтобы позже в него можно было добавить сохранение `{ groupGuid, items: [{ contactGuid, cellIndex }] }` на новый backend.
- **Файлы для изменений:** `src/widgets/quick-call-panel/model/use-quick-call-grid/**`, `src/widgets/quick-call-panel/ui/QuickCallPanel.vue`, `src/widgets/quick-call-panel/ui/QuickCallContactCard.vue`; при необходимости внутренний model/composable для edit/move state внутри `src/widgets/quick-call-panel/model/**`.
- **Ожидаемый результат:** В edit mode пользователь может открыть меню карточки, выбрать перемещение внутри группы и переставить контакт в свободную ячейку этой же группы. Порядок сохраняется локально в текущей frontend-сессии через `useQuickCallGrid`. Добавить смену карточек, если нажали на заполненную карточку, они меняются местами.
- **Проверка:** `npm run ts:check`; ручная проверка: включить edit mode, открыть меню карточки, выбрать `Переместить`, кликнуть свободную ячейку, убедиться что карточка переехала; проверить отмену по клику на исходную карточку и при выходе из edit mode.
- **Коммит после шага:** Да.
- **Нужно ли обновить project wiki:** Нет, если реализация совпадает с этим планом. Да, если по ходу изменится правило поведения перемещения.

## Шаг 2: Перемещение контакта между группами через существующий backend

- **Описание:** Перед реализацией сверить через MCP Swagger актуальные endpoint'ы добавления существующего контакта в группу и удаления контакта из группы. Реализовать сценарий `Переместить в другую группу`: после выбора пункта меню текущая карточка/группа визуально показывают pending state с уменьшенной opacity, перенос внутри исходной группы блокируется, клик по исходной карточке отменяет действие. При переключении на другой таб ПБВ остается в edit mode, и пользователь может выбрать свободную ячейку в целевой группе. По клику на свободную ячейку выполнить backend-последовательность: сначала добавить существующий контакт в целевую группу, затем удалить принадлежность контакта из исходной группы. После успешного ответа backend обновить списки контактов затронутых групп и положить контакт в выбранный `cellIndex` целевой группы через `useQuickCallGrid`. Ошибки пока логировать в консоль без отдельного UI error state.
- **Файлы для изменений:** `src/entities/contact/api/use-contact-api.ts`, `src/entities/contact/types.ts`, `src/widgets/quick-call-panel/model/**`, `src/widgets/quick-call-panel/ui/QuickCallPanel.vue`, `src/widgets/quick-call-panel/ui/QuickCallContactCard.vue`, `.ai/tasks/WUI-4864/case.md`; при необходимости `.ai/knowledge/wiki/domain/quick-call-panel.md`.
- **Ожидаемый результат:** В edit mode при наличии нескольких групп пользователь может выбрать `Переместить в другую группу`, перейти на другой таб, выбрать свободную ячейку и перенести контакт через существующий backend состава групп. Контакт исчезает из исходной группы и появляется в целевой группе в выбранной свободной ячейке.
- **Проверка:** MCP Swagger `describe_endpoint` по endpoint'ам добавления/удаления; `npm run ts:check`; ручная проверка с двумя группами: перенос в другую группу, отмена кликом по исходной карточке, запрет переноса в ячейку исходной группы, обработка ошибки через console log.
- **Коммит после шага:** Да.
- **Нужно ли обновить project wiki:** Да: зафиксировать стабильное поведение перемещения между группами и backend-последовательность, если она подтверждена реализацией.

## Шаг 3: Добавление контакта в активную группу через существующую модалку

- **Описание:** В edit mode по клику на плюс в свободной ячейке открыть существующую `BindingContactModal` из `@/widgets/binding-contact`. Модалка возвращает выбранный `Contact | null`. Если контакт не выбран или нет активной группы, ничего не делать. Если выбранный контакт уже есть в активной группе, ничего не делать и не отправлять backend-запрос. Если контакта нет в активной группе, добавить его в состав группы по тому же механизму, что перенос между группами: получить текущую группу через `/api/user/groups/{groupGuid}`, добавить `contactGuid` в `contactGuids`, выполнить `PUT /api/user/groups/{groupGuid}` с сохранением `name` и `type`. После успешного ответа обновить кэш контактов активной группы и локально положить контакт в выбранный `cellIndex` через `useQuickCallGrid`. Пользователь может быть в разных группах, но не должен дублироваться в одной группе.
- **Файлы для изменений:** `src/widgets/quick-call-panel/ui/QuickCallPanel.vue`, `src/widgets/quick-call-panel/model/use-quick-call-contact-transfer/use-quick-call-contact-transfer.ts`; при необходимости `src/entities/group/model/use-group-store.ts`, `src/entities/contact/types.ts`, `.ai/tasks/WUI-4864/case.md`.
- **Ожидаемый результат:** В режиме редактирования клик по плюсу открывает старую модалку выбора контакта. Выбранный контакт, которого еще нет в активной группе, добавляется в backend-состав группы и появляется в выбранной ячейке. Повторный выбор контакта, уже присутствующего в активной группе, не делает backend-запрос и не создает дубль.
- **Проверка:** `npm run ts:check`; ручная проверка: открыть edit mode, нажать плюс, выбрать контакт из старой модалки, убедиться что он добавился в выбранную ячейку; повторить выбор уже добавленного контакта и убедиться, что дубль не появился. Новые тесты в этом шаге не добавлять.
- **Коммит после шага:** Да.
- **Нужно ли обновить project wiki:** Нет, если реализация совпадает с планом; итоговое обновление wiki вынесено в следующий шаг.

## Ограничения для этой части

## Корректировка шага 2 от 2026-06-04

- Найден backend-кейс RTU-12674/WUI-3859: перенос между группами нужно выполнять через `/api/user/groups`, обновляя полный состав `contactGuids` у исходной и целевой групп.
- `PUT /api/user/contacts/{guid}` не подходит для переноса `contactType=user`: backend возвращает `The Contact must have type 'ExternalContact'`.
- `/api/v1/user/client/contact` не является целевым контрактом для ПБВ в этом шаге.
- Фактическая последовательность шага 2: `GET /api/user/groups/{sourceGroupGuid}` + `GET /api/user/groups/{targetGroupGuid}`, затем `PUT /api/user/groups/{targetGroupGuid}` с добавленным `contactGuid`, затем `PUT /api/user/groups/{sourceGroupGuid}` без `contactGuid`.

- Новый backend хранения order/positions пока не используется.
- Локальное изменение порядка внутри группы не переживает reload до подключения нового backend.
- Нативные `<button>` для новых action controls не использовать; кликабельные действия делать через `wui-btn`.
- Стили контекстного меню остаются простыми: пользователь отдельно доведет визуал.
- Новые тесты не добавлять в основных шагах без отдельного согласования; тестовый шаг можно сделать позже, когда сценарий стабилизируется.
