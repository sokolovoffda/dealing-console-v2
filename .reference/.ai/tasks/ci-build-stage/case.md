# CI — опциональная stage-сборка без проверки контроллера

## Исходная задача

Добавить в CI сборку stage без проверки наличия контроллера. Джоба должна быть опциональной.

## Уточнения пользователя

- 2026-08-24: Без Jira-тикета.
- 2026-08-24: Production-логин блокирует вход без контроллера (`MODE === 'production'`). Stage-сборка (`npm run build:stage`) эту проверку не включает.
- 2026-08-24: Существующие джобы `build` и `build-deb` не менять. Добавить опциональную джобу, которая собирает `.deb` через `npm run build:stage`.

## Ограничения

- Не менять runtime-логику логина и App.vue.
- Не менять production-сборку debian-пакетов.
- Джоба не должна блокировать пайплайн, если её не запускали.

## Связанные материалы

- `.gitlab-ci.yml`
- `src/pages/login/ui/LoginPage.vue` — проверка контроллера только при `MODE === 'production'`
- `package.json` — скрипт `build:stage`
