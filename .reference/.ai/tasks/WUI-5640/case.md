# WUI-5640 — Пробел в названии группы считается окончанием названия

## Исходная задача

**Jira:** [WUI-5640](https://jira.satel.org/browse/WUI-5640)

На демо-стенде (РТУ `2.3.2-11s_Smolensk`) при создании групп «Группа 1» и «Группа 2» вторая не создаётся из‑за «совпадения названий»: старый RTU обрезает имя по пробелу и сравнивает только префикс («Группа»).

## Уточнения пользователя

- 2026-09-11: временный обход без смены беков — при отправке на RTU склеивать слова через `_` (пробелы → `_`).
- Делается вместе с временным обходом WUI-5642.
- Позже вернёмся к обычному поведению после обновления RTU.

## Ограничения

- Только FE-обход; RTU и turret-admin не меняем.
- Обход временный и должен легко выключаться/удаляться.
