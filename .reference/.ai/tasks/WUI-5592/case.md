# WUI-5592 — Нет скролла в очереди карточки вызова

## Исходная задача

При 6+ вызовах в очереди 6-й вылезает за пределы карточки; скроллбар не появляется.

ОР: видно ~5 звонков + скролл.

## Уточнения пользователя

- 2026-09-07: пока простой скролл (без стрелок); стрелки скролла — позже.
- Без отдельного плана реализации — точечный фикс.

## Что сделано

- Правая колонка `CallCardLayout` ограничена высотой карточки (`h-full min-h-0 overflow-hidden`).
- `CallCardQueuePanel` / `CallCardHistoryPanel` — `h-full` + `overflow-y-auto`, чтобы скролл срабатывал при переполнении.
