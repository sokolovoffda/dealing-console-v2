# WUI-5546 — Карточка вызова трубки перекрывает нижнюю панель

## Исходная задача

При нажатии на кнопку трубки на нижней панели карточка вызова перекрывает footer вместо того, чтобы отображаться выше неё.

- ОР: карточка выше нижней панели
- ФР: карточка перекрывает нижнюю панель
- Note: только на пульте (Electron), на Web не воспроизводится
- Env: 3.0.0-alpha.12 dealing-console

## Ограничения

- Не ломать web-поведение
- Карточка должна оставаться над footer (wiki: «открывается снизу над footer»)
- Предпочтительный паттерн фикса — как `SettingsSidebarFooter` (ручной `relative` + `absolute bottom-full`), не CSS Anchor Positioning
