# IPC IQ/MAX TOUCH — Settings простым языком

Источник User Guide (Unigy 4.3), Chapter 11.  
**Admin Settings** и **Diagnostic Tool** в User Guide почти не описаны — детали в Hardware Installation Manual (у нас файла нет).

---

## Как устроен экран Settings

Три блока слева:

| Блок | Кто видит | Зачем |
|------|-----------|--------|
| **USER SETTINGS** | обычный трейдер/оператор | личные предпочтения работы |
| **ADMIN SETTINGS** | только админ-логин | железо, сеть, «железо» станции |
| **Diagnostic Tool** | если админ разрешил | снять дамп/диагностику для поддержки |

Справа — содержимое выбранного пункта.  
Почти всё сохраняется сразу (без Save). Исключение — смена пароля (там есть Save/Cancel).

## Словарь (иначе половина непонятна)

| Термин | Простыми словами |
|--------|------------------|
| **Turret / пульт** | рабочая станция трейдера: экран + трубки + кнопки линий |
| **Line / линия** | телефонная линия / «кнопка линии» на пульте |
| **Intercom / ICM** | внутренняя связь между пользователями Unigy (как «внутренняя» между трейдерами), не обычный городской звонок |
| **DDI** | Direct Dial Inward — прямой внешний/городского типа номер на extension пользователя (входящие «снаружи» на ваш номер) |
| **Diversion** | переадресация: «если мне не ответили / я занят — кинь звонок туда-то» |
| **RNA** | Ring/No Answer — звонили, не ответили |
| **BRNA** | Busy + RNA — занят **или** не ответили |
| **Dual Divert** | два разных направления: занятость → номер A, неответ → номер B |
| **CLI** | Calling Line Identification — что показывать на кнопке/экране про того, кто звонит (имя, номер и т.д.) |
| **Hands-free / HFM** | разговор без трубки (динамик + микрофон стола) |
| **Speaker channel** | отдельный «канал спикера» — постоянная/полупостоянная аудиолиния (hoot и т.п.), не обычный peer call |
| **Latch** | «защёлкнуть» микрофон/канал: нажал — держится открытым, пока не отожмёшь снова |
| **PTT (Push to Talk)** | говорить только пока держишь кнопку (как рация) |
| **Favorites** | панель кнопок быстрого доступа (линии, speed dial, diversion buttons…) |
| **UMS** | Unigy Management System — админка на сервере, откуда админы правят профили |

# A. USER SETTINGS (подробно)

## 1. Account Info — «Кто я»

**Что показывает**
- Username — логин
- Personal / Intercom extension — ваш внутренний и intercom-номер (если совпадают — один)

**Что можно сделать**
- Сменить пароль: текущий → новый → подтверждение → Save

**Как работает**
- Это карточка аккаунта, не «настройки звонков».
- Пароль может быть из AD — тогда сменить с пульта нельзя.
- Политика паролей (минимальный возраст и т.д.) задаётся на сервере.

**Зачем трейдеру:** посмотреть свой номер / сменить пароль без IT.

---

## 2. Diversion — «Куда девать входящие, если я не беру»

Два разных мира diversion:

### 2.1 ICM Diversion (межком / intercom)
- Только point-to-point intercom → другому Unigy-пользователю.
- Не работает для group answer / group talkback / group calls.

**Типы**
- **No Diversion** — всё идёт ко мне
- **Immediate** — сразу на другой extension, мне даже не звонит
- **Busy** — переадресация, если я «занят» (в т.ч. сценарии с hands-free)
- **Ring/No Answer** — звонили N времени / не ответил → увести
- **Busy/Ring/No Answer** — занят **или** не ответил

Поле **Divert To** — куда увести. Кнопка Enable включает правило.

### 2.2 DDI Diversion (обычная line / «forward»)
- Входящие на мой line/extension → любой номер/extension.
- Можно добавить несколько DDI-правил.
- Есть **Dual Divert**: busy → один номер, no-answer → другой.

**Как работает в жизни**
1. Выбираешь линию «с которой» (Divert From) — вручную или из Favorites.
2. Выбираешь условие (Immediate / Busy / RNA / …).
3. Указываешь Divert To.
4. Enable.

**Важно**
- Voice mail тоже считается diversion: новое правило diversion может перебить voicemail.
- ICM diversion по умолчанию **не переживает** logout (если админ не включил persist).
- DDI обычно persist через login/logout, но после logout список на экране Settings может «пропасть из UI» — отключение = поставить No Diversion.

**Аналог у нас:** «Обработка входящего вызова» (forwarding rules).

## 3. Call Handling — «Как вести себя при звонках»

Это не переадресация, а **поведение UI/оповещений**.

### 3.1 Auto-answer Intercom
- **ON** — intercom сам берётся hands-free (без нажатия).
- **OFF** — надо отвечать вручную.
- По умолчанию ON.

*Смысл:* внутренние «переклички» между трейдерами не отвлекают лишним Accept.

### 3.2 Show Popup Notifications
Всплывашка входящего, даже если вы не на главном экране (например в Settings).

Галочки по типам:
- Intercom Calls
- High Priority Calls
- Low Priority Calls

*Смысл:* не пропустить важный звонок, сидя в другом приложении.  
В гайде прямо сказано: без Expansion Module без popup из Settings входящий можно не взять, пока не закроешь Settings.

### 3.3 Color Coding
Цвета кнопок по **приоритету** и **состоянию** линии (в Favorites / Activity Monitor / Call Notification).

Можно:
- покрасить каждый статус/приоритет
- Restore Defaults

Цвета статуса рисуются в нижней части кнопки, фон Favorites — в верхней (чтобы не путать).

*Смысл:* глазами отличать «горит важный» / «в разговоре» / «hold» и т.п.

**Частичный аналог у нас:** Приоритизация (цвет/рингтон на контакт), но не глобальная палитра состояний.

### 3.4 Ringtone
Разные мелодии на типы:
- High Priority
- Low Priority
- Pending
- Messages

*Смысл:* ухом понимать «что именно звонит», не глядя на экран.

**У нас:** один рингтон + громкость + upload; per-contact в Приоритизации.

### 3.5 CLI (что писать про звонящего)
Варианты отображения:
- **Name** — только имя
- **Number** — только номер
- **Toggle** — имя ↔ номер по очереди
- **Match** — подпись с кнопки Favorites, если есть; иначе имя / Not Available
- **Lookup** — поиск в базе Unigy:
  - формат имени (Имя Фамилия / Фамилия, Имя)
  - показывать ли Company
  - приоритет источников: Speed Dial / Personal Directory / Enterprise Directory (0 = не использовать, 1 = высший)

*Смысл:* на кнопке линии не «сырой номер», а понятный caller ID.

## 4. Date & Time — «Как писать дату/время»

Только **формат отображения**, не синхронизация часов с сервером.

- Time: 12 Hour / 24 Hour
- Date: MM-DD-YY, MM-DD-YYYY, DD-MMM-YY, DD-MM-YYYY, YYYY-MM-DD

Часы станции синхронятся через NTP (это уже System/Admin мир).

## 5. Device / Volume — «Экран и громкости станции»

| Настройка | Что делает |
|-----------|------------|
| **Display language** | язык UI (EN/FR/DE/ZH/…); часть экранов не переводится (login, Admin, данные из БД) |
| **Font magnification** | Small / Medium / Large (~±4px); Large иногда откатывается к Medium, чтобы не ломать вёрстку |
| **Brightness** | яркость; при Expansion Module — два слайдера (primary + expansion), по умолчанию слинкованы |
| **Sleep timer** | через 5–30 мин бездействия — screensaver (бережёт экран/энергию) |
| **Default receive volume** | базовая громкость **приёма** для Handset и Hands-Free (1–40) |
| **Ringer volume** | громкость звонка (0–5) |

*Смысл:* комфорт оператора на железе пульта, не бизнес-логика звонков.

**У нас:** язык есть; громкость входящего есть; font/brightness/sleep — по сути нет (или не в Settings).

## 6. System Info — «Паспорт станции» (только чтение)

Оператор **смотрит**, не меняет:

| Блок | Что внутри |
|------|------------|
| Station Network | hostname, domain, IP, DHCP, gateway, MAC |
| Servers | к какой zone/серверам привязан пульт |
| NTP Info | серверы точного времени |
| VoIP Parameters | порты/параметры голоса (signalling, bearer, DSCP…) |
| Software Version | версии ПО/ядра/bootrom, part number, serial, touch vendor |
| Deployment | лицензии, desk location |

*Смысл:* для саппорта «скажи IP / версию / zone» без лезания в Admin.

**У нас:** клик по version → network interfaces — зародыш этого раздела.

---

## 7. Speakers — «Как защёлкивать speaker-каналы»

Не про выбор устройства Windows, а про **поведение latch** на speaker UI.

1. **Slide-to-latch** Enabled/Disabled  
   Свайп по иконке канала вверх = «защёлкнуть» (микрофон/канал держится), ещё раз = снять.

2. **Speaker Groups latch mode**
   - **Push to Talk** — говоришь, пока держишь
   - **Push to Latch/Unlatch** — тап открыл, тап закрыл

*Смысл:* стиль работы с hoot/speaker groups — рация vs «защёлкнул и говоришь».

**У нас близко:** Goose mode (stateful / PTT) + PTT scope в Медиа устройствах.

# B. ADMIN SETTINGS

### Что точно сказано в User Guide
- Видны **только administrative users**.
- Описание — в **IQ/MAX TOUCH Turret Hardware Installation Manual** (документа у нас нет).
- Login/Admin screens **не локализуются** вместе с user UI.

### Что из этого следует (логика, не дословный список из PDF)

System Info показывает **результаты** админской конфигурации. Обычно Admin на таком железе крутит именно это:

| Ожидаемая зона Admin | Зачем |
|----------------------|--------|
| Сеть станции (IP/DHCP/gateway/DNS/hostname) | подключить пульт в LAN |
| Привязка к zone / Unigy servers | куда регистрироваться |
| NTP | правильные часы/таймстемпы |
| VoIP / SIP-like параметры | голос, порты, DSCP/QoS |
| Лицензии / deployment / desk location | что станции разрешено |
| Возможно: обновления ПО, периферия, expansion, diagnostics enable | эксплуатация железа |

**Важно:** это **вывод по System Info + типу устройства**, не оглавление Admin из мануала.  
Чтобы дать точный список полей Admin — нужен Hardware Installation Manual.

# C. Diagnostic Tool

### Что сказано в User Guide
- Доступен, **только если админ включил** инструмент для пользователя/станции.
- Генерирует **diagnostic data** для анализа и troubleshooting.
- Детали — снова в Hardware Installation Manual.

### Как понимать
Это не «настройка», а **сервисная кнопка**: снять пакет логов/состояния станции и отдать поддержке/инженеру.  
Аналог в нашем мире: «скачать логи Electron / controller / network dump» (если сделаем).

# Карта «зачем это человеку»

```
USER
  Account        → кто я / пароль
  Diversion      → куда уводить недоступные звонки
  Call Handling  → как меня уведомлять и как рисовать звонки
  Date & Time    → как показывать дату
  Device/Volume  → комфорт экрана и громкостей
  System Info    → показать инженеру паспорт станции
  Speakers       → PTT/latch для speaker-каналов

ADMIN            → сеть/серверы/VoIP/железо (закрыто от трейдера)
DIAGNOSTIC       → снять дамп для разбора проблем
```

---

# Что из этого релевантно нашему пульту (коротко)

Брать в дизайн в первую очередь:
1. Call Handling (popup / CLI / рингтоны по типу) — у IPC это ядро UX
2. Account Info
3. Date & Time
4. System Info как нормальный раздел
5. Device volumes / font (если desktop это умеет)
6. Speakers/PTT — у нас уже есть, надо яснее сгруппировать

Admin + Diagnostic — отдельный контур «для инженера», не мешать в user Settings MVP без Hardware Manual.
