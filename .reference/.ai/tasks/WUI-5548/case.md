# WUI-5548 — Уведомление при создании группы с существующим именем

## Исходная задача

При создании группы ПБВ с уже существующим именем показывается сырое уведомление про 409 / network error.

ОР: понятное сообщение, что группа с таким именем уже есть.

## Что сделано

- `resolveGroupApiError` — расширяемый маппинг HTTP status → code + i18n key (сейчас 409 → `GroupNameAlreadyExists`).
- `useGroupStore.notifyError` использует маппер; неизвестные ошибки — по-прежнему `error.message` / Network Error.
