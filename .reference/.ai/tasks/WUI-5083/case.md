# WUI-5083 — Кнопки пульта, цвета и финализация footer

## Исходная задача

В рамках WUI-5083 нужно разобраться с кнопками и цветами пульта, затем зафиналить footer.

Финальное решение по ТЗ: theme-токены кнопок пульта не заносить в `common-library`, потому что это цвета проекта консоли. В `dealing-console-ui` они должны жить в глобальных стилях приложения, значения должны ссылаться на палитру `@wui/common-library` через CSS variables.

Нужно создать локальный компонент `MyBtn`, который оборачивает `WuiBtn`, использует `variant="neut"` и `state="alpha"` как безопасную базу, а реальный визуал задаёт локальными `my-btn` классами. Цвета `MyBtn` берутся из глобальных theme-файлов приложения в `src/app/assets/styles`.

После подготовки кнопок и цветов нужно применить их в footer и довести footer до финального вида.

- 2026-06-29: Не добавлять отсутствующие в дизайнерском источнике токены, в частности не придумывать `callcon` alpha/toggle наборы.

## Ограничения

- Не менять API `common-library` в рамках этой задачи.
- Не добавлять новые зависимости.
- Не копировать палитру `colors.css`; локальные theme-токены должны ссылаться на существующие CSS variables палитры common-library. Если дизайнерская выгрузка ссылается на отсутствующий alias, использовать уже согласованный существующий alias или точечное значение только внутри theme-файла.
- Поддержать темы `light-1` и `lsDark-1`.
- Реализовать состояния `default`, `hover`, `pressed`, `disabled`; `focus` не реализовывать.
- Тесты добавлять/обновлять после стабилизации визуального контракта.
- Выполнять работу по шагам; один шаг соответствует одному будущему коммиту пользователя.
