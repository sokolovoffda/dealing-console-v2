# Кейс: WUI-5637 — Виртуальная клавиатура для текстового ввода

## Описание текущей части кейса

Подключить плавающую виртуальную клавиатуру (`KeyboardModal` + `KeyboardPad`) к созданию группы на ПБВ, поиску в справочнике и поиску в истории. UX: в поиске — по focus; в создании группы — auto-open при открытии модалки, повторное открытие по клику/focus в input; везде — закрытие и перетаскивание.

# План реализации: Плавающая клавиатура (ПБВ / справочник / история)

## Шаг 1: Подготовить `KeyboardModal` к overlay-сценарию

- **Описание:** Проверить и при необходимости доработать `KeyboardModal`, чтобы плавающая клавиатура корректно работала поверх `AppModal` и панелей: не обрезалась overflow родителя, была выше dialog-слоя, drag/close сохранялись. Ожидаемое решение — `Teleport` в `body` + `position: fixed` (и достаточный `z-index`), без смены публичного API emits (`onKeyTap`, `close`). Учесть уже существующую задержку `v-click-outside`, чтобы клавиатура не закрывалась мгновенно при открытии. Не менять `KeyboardPad` и логин / `ChangeContactsModal`.
- **Файлы для изменений:** `src/shared/ui/modals/keyboard-modal/KeyboardModal.vue` (при необходимости стили рядом)
- **Ожидаемый результат:** `KeyboardModal` можно открыть из любой точки UI; она плавает по экрану, перетаскивается за header, закрывается крестиком / hide-key / click-outside.
- **Проверка:** ручная — открыть временным wiring или в Story/существующем `SearchBar` в isolation; визуально поверх контента; drag + close.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Нет

## Шаг 2: ПБВ — клавиатура в `CreateGroupModal` (WUI-5637)

- **Описание:** В `CreateGroupModal` подключить `KeyboardModal`: при монтировании `keyboardVisible = true`; `@focus` / клик по полю названия снова открывает; `@close` скрывает. Нажатия клавиш пишут в `name` (letter / backspace), по аналогии с `SearchBar` / `KeyboardWithTextModal`. Внешний вид поля не менять (`wui-input` size 48).
- **Файлы для изменений:** `src/widgets/quick-call-panel/ui/CreateGroupModal.vue`
- **Ожидаемый результат:** Открытие «Создать группу» сразу показывает плавающую клавиатуру; ввод имени с неё работает; закрытие и повторное открытие по focus в input работают; подтверждение создания по-прежнему от кнопки модалки.
- **Проверка:** ручная в Electron/web — ПБВ → создать группу → ввод ≥3 символов → Создать; закрыть клавиатуру → клик в input → снова открылась.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Нет

## Шаг 3: Справочник и история — клавиатура на поиске

- **Описание:** В `PhoneBookPanel` и `CallHistoryPanel` к существующим search-input добавить тот же паттерн, что в `SearchBar`: focus → показать `KeyboardModal`, close → скрыть, key-tap → менять `searchText`. Стили input (`size="48"`, placeholder «Поиск») сохранить. `SearchBar` либо не трогать, либо точечно выровнять под этот паттерн только если удобно переиспользовать без ломки API — приоритет минимальному diff в двух панелях.
- **Файлы для изменений:** `src/widgets/phone-book/ui/PhoneBookPanel.vue`, `src/widgets/call-history/ui/CallHistoryPanel.vue`
- **Ожидаемый результат:** Фокус в поиск справочника/истории открывает плавающую клавиатуру; ввод фильтрует как раньше; клавиатуру можно закрыть и снова открыть фокусом.
- **Проверка:** ручная — справочник и история: focus → клавиатура → ввод → debounce-поиск; close → повторный focus.
- **Коммит после шага:** Да
- **Нужно ли обновить project wiki:** Да, кратко: `frontend/components.md` — правило «текстовый ввод на пульте → плавающий `KeyboardModal`», список мест (логин/выбор контактов остаются со встроенным `KeyboardPad`).
