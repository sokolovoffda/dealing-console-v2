## Шаг-дисциплина проходки (как работать)

1. Пользователь пишет: `начинаем блок N` (или `одобряю` на весь план + старт с блока 1).
2. Агент поднимает чеклист блока, помогает пройти сценарии / сверяет код с ожиданием, фиксирует `🐛`/`⚠️`.
3. По каждому багу: минимальный фикс → проверка → пользователь коммитит.
4. Не переходим к блоку N+1, пока пользователь не скажет, что блок N закрыт (или явно `скипаем остаток блока / идём дальше`).
5. После всех блоков — короткий итоговый список для QA (что покрыто, known issues, open questions).
