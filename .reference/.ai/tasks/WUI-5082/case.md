# WUI-5082 — Правки кнопок хедера

## Исходная задача

В чате выполняются UI-правки хедера без отдельного плана.

Jira: https://jira.satel.org/browse/WUI-5082

Нужно привести кнопки хедера к состояниям из референсного скриншота:

- левая часть:
  - кнопка `M` и кнопки `1-5` — обычные кнопки с активным состоянием;
  - из кнопок `M` и `1-5` может быть выбрана только одна;
  - последняя кнопка слева — toggle-кнопка режима редактирования рабочих столов;
  - toggle редактирования рабочих столов может быть выбран только если выбран один из рабочих столов, в остальных случаях он disabled;
- правая часть:
  - кнопки монопольных страниц;
  - выбрана может быть только одна;
  - это не toggle-кнопки, а обычные кнопки с активным состоянием;
- обычные кнопки и toggle-кнопки должны иметь одинаковые стили состояний.

## UI-состояния кнопок

- Не выбрана / не нажата:
  - background: без фона
  - icon: `comp/tog/brandcon/icon/inactive/def`
- Hover:
  - background: `comp/tog/brandcon/bg/inactive/hov`
  - icon: `comp/tog/brandcon/icon/inactive/def`
- Disabled:
  - background: без фона
  - icon: `comp/tog/brandcon/icon/inactive/dis`
- Выбрана / нажата:
  - background: `comp/tog/brandcon/bg/active/def`
  - icon: `comp/tog/brandcon/icon/active/def`
