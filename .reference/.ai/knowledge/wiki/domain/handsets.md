# Трубки footer

## Назначение

Страница фиксирует текущую модель двух трубок в footer dealing console: выбор активной трубки пользователем и отображение статуса линии на каждой трубке.

## Текущее понимание

В footer есть две трубки: левая и правая. Всегда выбрана ровно одна трубка. Выбранная трубка и статус линии на трубке являются разными осями состояния.

Трубка может не иметь вызова и быть свободной. Если на трубке есть активность, визуальный статус отражает состояние линии: активный вызов, удержание, конференция и другие будущие состояния. Активность может быть одновременно на двух трубках, например одна трубка показывает активный вызов, а другая удержание.

В WUI-5081 выбранная трубка footer связана с карточкой вызова. Клик по трубке выбирает ее и открывает карточку этой трубки. При наличии сессии выбранная трубка окрашивается статусом выбранной/основной сессии, а невыбранная трубка при наличии сессии показывает соответствующую иконку и цвет статуса без автоматического переключения выбранности.

## Основные сущности

- `FooterHandsetId` — идентификатор трубки: `left` или `right`.
- `FooterHandsetStatus` — статус линии на трубке: в базовой реализации `free`, задел под `call`, `hold`, `conference`.
- `selectedHandsetId` — выбранная пользователем трубка.

## Пользовательские сценарии

- При загрузке footer по умолчанию выбрана левая трубка.
- Пользователь может переключить выбранную трубку кликом по левой или правой трубке.
- В будущей полной реализации клик по трубке должен выбирать её и открывать окно вызова/линии, связанное с этой трубкой.

## Правила и ограничения

- Всегда выбрана ровно одна трубка.
- Выбранность не должна затирать статус линии.
- Статус линии выбирает цветовую группу (`neutcon`, `callcon`, `waitcon`, `confcon`).
- Выбранность выбирает только состояние внутри цветовой группы: `active` или `inactive`.
- Две трубки могут одновременно отображать разные активные статусы.
- Трубки не используют `MyBtn`, потому что это не обычная button/toggle-модель, а selector линии со статусом.
- **Soft-disable (`enabled=false`, WUI-5528):** футер не пустеет. OFF без активности → disabled (клик no-op). OFF с активностью → подсветка статуса как обычно; клик открывает карточку (просмотр); Answer / hardware off-hook → toast. Ровно одна enabled → она становится `selectedHandsetId` (resolve fallback). Обе OFF → selected сохраняется визуально (обычно last requested).
- Карточка вызова: open при lockdown возможен, если на выбранной трубке есть активность линии.
- **ПБВ (`ContactCard`):** активность/presence не гасятся от `enabled`; клик «взять/позвонить» без usable device → toast (карточка остаётся кликабельной).
- Входящий вызов на невыбранной трубке не переключает выбранную трубку автоматически; он только подсвечивает статус этой трубки.
- Очередь карточки относится к выбранной трубке.

## Edge cases

- Если левая трубка в удержании, а пользователь выбирает правую свободную трубку, левая должна остаться в визуальном статусе удержания.
- Если обе трубки имеют активность, каждая трубка отображает собственный статус независимо от выбранной трубки.
